# IAM Access Analyzer policy validation

`aws accessanalyzer validate-policy` on every policy the stack deploys with `--activity-stream` (identity policies, trust policies, both KMS key policies, both S3 bucket policies and the SNS alarm topic policy), run against a deployed stack on 2026-11-20 (after adding `aws:SourceArn` to the scheduler and Firehose trust policies). Resource ARNs are generated by CloudFormation from the stack name.

| Policy | Findings |
|---|---|
| <stack>-anchor-function / anchor (identity) | none |
| <stack>-anchor-function trust policy | none |
| <stack>-anchor-scheduler / invoke-anchor (identity) | none |
| <stack>-anchor-scheduler trust policy | none |
| <stack>-activity-firehose / archive (identity) | none |
| <stack>-activity-firehose trust policy | none |
| signing key policy | none |
| activity stream key policy | none |
| anchor bucket policy | none |
| activity archive bucket policy | none |
| alarm topic policy (SNS) | none |
